=== CI/CD = an automated software development process that 
bridges the gap between development and operations team. (Allow developer to ship update to end-user faster).
- CI = Continuous Integration = where developer frequently merge their code changes into central repository (Github or Gitlab).
- CD = Continuous Delivery = The code is automatically build and tested, but human need to manual click a button to approve the final release to production.
- CD = Continuous Deployment = The code passes all pipeline steps and is automaticaly release to user with zero manual.
